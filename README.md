# 🗣️ 통TONG

**말이 안 통하는 사람과, 각자 자기 폰으로, 각자의 언어로 대화하세요.**

내가 한국어로 말하면 상대 화면엔 상대 언어로, 상대가 말하면 내 화면엔 한국어로 —
카톡처럼 채팅으로 쌓이고, 소리로도 읽어줍니다. **상대방은 앱 설치도 필요 없어요.**

---

## 📲 설치 방법 (안드로이드)

1. 이 페이지에서 **[Releases](../../releases)** 를 누르세요.
2. 가장 위(최신 버전)의 **`app-release.apk`** 를 눌러 다운로드하세요.
3. 다운로드가 끝나면 알림을 눌러 파일을 여세요.
   (안 보이면 **내 파일 → 다운로드** 폴더에서 `app-release.apk`를 누르세요)
4. *"출처를 알 수 없는 앱"* 경고가 뜨면 → **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 누르세요.
   (구글 플레이에서 받은 앱이 아니라서 나오는 안내일 뿐, 정상입니다)
5. 홈 화면에 **통TONG** 아이콘이 생기면 완료!

> 🍎 **아이폰 사용자는?** 앱 설치 없이 웹으로 참여할 수 있어요. 아래 사용 방법을 보세요.

---

## 💬 사용 방법

**앱이 있는 사람 (방 만들기)**

1. 통TONG 앱 열기 → 내 언어 선택 → **새 대화 만들기**
2. 화면에 **QR코드**가 떠요. 상대에게 보여주세요.

**상대방 (앱 없어도 OK — 아이폰·갤럭시 다 가능)**

1. 폰 **카메라**로 QR을 찍고, 뜨는 링크를 누르면 웹페이지가 열려요.
2. 자기 언어만 고르면 → 바로 연결!

**대화하기**

- 앱: 🎤 버튼을 누르고 말하면, 말이 끝날 때 자동으로 전송돼요.
- 웹: 입력칸을 누르고 **키보드의 🎤 마이크**로 말하거나 문자로 입력하세요.
- 서로의 말이 **자기 언어로 번역되어** 채팅으로 쌓이고, 소리로도 읽어줍니다.

## ❓ 자주 묻는 것

**Q. 무료인가요?** — 네, 전부 무료입니다.
**Q. 인터넷이 필요한가요?** — 네, 양쪽 다 인터넷(와이파이/데이터)만 되면 어디서든 연결돼요.
**Q. 마이크가 안 돼요.** — 처음 🎤를 누를 때 나오는 **마이크 권한 허용**을 눌렀는지 확인하세요. (폰 설정 → 앱 → 통TONG → 권한에서도 켤 수 있어요)
**Q. 대화 내용이 저장되나요?** — 서버에 저장하지 않아요. 화면을 닫으면 사라집니다.
