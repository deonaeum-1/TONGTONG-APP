# 통TONG 앱

대면 실시간 통역 채팅 앱. 각자 자기 폰에서, 각자의 언어로.

## 이 저장소에 파일을 올리면 GitHub이 자동으로 안드로이드 설치파일(APK)을 만들어줍니다.

1. 이 폴더의 내용 전체(`.github` 폴더 포함!)를 GitHub 저장소에 업로드
2. 저장소의 **Actions** 탭에서 "Build Android APK"가 자동 실행됨 (10~15분)
3. 끝나면 저장소 **Releases**에 APK 파일이 생김 → 갤럭시에서 다운로드해 설치

## 구성
- `lib/main.dart` — 앱 전체 코드 (언어선택 → 방 만들기/코드 참가 → 통역 채팅)
- `pubspec.yaml` — 사용 라이브러리 (폰 내장 음성인식/음성출력, MQTT 연결, 무료 번역)
- `.github/workflows/build.yml` — 자동 빌드 설정

## 기능
- 방 코드 5자리로 두 폰 연결 (인터넷만 되면 어디서나)
- 폰 내장 음성인식: **아이폰·안드로이드 모두 🎤 버튼으로 말하기 가능**
- 말이 끝나면 자동 전송 → 상대 언어로 번역되어 도착 → 소리로 읽어줌(TTS)
- 8개 언어
